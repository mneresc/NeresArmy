# Perfis didáticos

- `law-afo`: regra, sujeito, condição, prazo, exceção, consequência, modalidade e
  pegadinha.
- `mathematics`: ideia, variáveis, fórmula, procedimento, exemplo existente e
  verificação.
- `technical-it`: função, componentes, entrada/saída, fluxo, estado, código e
  diagnóstico.
- `hybrid`: classifica cada seção entre os perfis anteriores.
- `generic`: composição conservadora quando a fonte não sustenta outro perfil.

O perfil muda a apresentação, nunca autoriza fatos.
