# Neres Inclusive Learner Profile

Skill conversacional para conduzir uma anamnese pedagógica adaptativa e produzir um
perfil operacional, contextual e provisório. O perfil pode ser consumido por skills
de estudo, questões, acessibilidade e revisão.

## O que produz

```text
learning/LEARNING_PROFILE.md
```

O documento registra objetivos, fontes, evidências, barreiras funcionais, apoios,
forças, MDAR por competência, incertezas e regras de handoff. Não é diagnóstico,
laudo, teste de inteligência nem classificação de estilo de aprendizagem.

## Instalação

```powershell
npx skills@latest add mneresc/NeresArmy --skill neres-inclusive-learner-profile
```

## Uso

```text
Use $neres-inclusive-learner-profile para mapear meu perfil de aprendizagem uma pergunta por vez.
```

Leia o [Cookbook](docs/COOKBOOK.md) para fluxo, atualização e validação.
