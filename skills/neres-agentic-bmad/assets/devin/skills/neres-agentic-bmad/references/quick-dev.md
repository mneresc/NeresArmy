# Quick-dev protocol

Use only for tiny/small, local, low-risk work affecting one to five expected files
with no architecture, migration, auth or cross-cutting contract change.

## Phase 1 — mandatory stop

Build the CapabilityMap, ask the reader for a ContextPack and return a QuickPlan
with classification, decisive diagnosis, inspected/expected files, implementation
steps, verification, estimated scope and risks. Do not edit. End with:

`Plano pronto. Aguardando autorização para implementar.`

## Phase 2 — later authorization only

After a later explicit approval, convert the QuickPlan into one to three
TaskPackets. Use discovered equivalent skills/MCPs and the bounded Dev Nerinhos.
Run deterministic tests and QA. If scope or risk changes materially, stop for a new
decision.
