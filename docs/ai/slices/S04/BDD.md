# S04 — BDD

1. Grafo visual de três nós e duas arestas ordenadas atinge score 5.
2. Grafo com menos de três elementos não vira diagrama.
3. Tipo visual mapeia para um dos cinco tipos Archify.
4. Input preparado preserva conjuntos e labels autorizados.
5. Output exato passa validação topológica.
6. Nó novo, aresta nova ou direção invertida falham.
7. Adapter saudável gera HTML e SVG.
8. Build incorpora `![[assets/x.svg]]` e link interativo.
9. Path explícito inexistente falha com diagnóstico.
10. Detecção ausente registra aviso sem perder a V2 textual.
