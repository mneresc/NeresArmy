# S03 — BDD

1. Manifest com hash correspondente produz evidência textual supported.
2. Hash divergente falha fechado antes de usar a análise.
3. Tabela preserva células vazias e `[ilegível]`.
4. Fórmula preserva LaTeX literal.
5. Diagrama preserva nós, arestas, direção e confiança.
6. Imagem ilegível cria callout de incerteza e nenhum fato certo.
7. Nota contendo apenas embed vira V2 quando há manifest do agente.
8. OpenAI sem autorização, key ou model não chama transporte.
9. OpenAI autorizado envia somente a imagem corrente e retorna schema validado.
10. Provedor `none` não chama serviço e mantém imagem como pending.
